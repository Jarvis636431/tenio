# 高德-周边搜索

基于高德地图的周边地点搜索服务，支持按关键词和城市查询周边位置、评分、营业时间等商户详细信息。

## 高德地点搜索服务-周边搜索

输入关键词和城市，返回查询信息。

## 使用说明
1、可以使用 fetch 示例的 url 和 headers 信息
2、响应数据中获取data字段为展示结果

### 接口地址

`POST /api/saas/tool/v1/plugin/run/38789`

**Fetch 请求配置：**
```javascript
{
  method: "POST",
  url: "https://joycode-api.jd.com/api/saas/tool/v1/plugin/run/38789",
  headers: {
    "Content-Type": "application/json",
    "Authorization":  "3zifZwB+NLjWVPQCHxUzQgSBVoni18D6LfWTIftyeyQ="
  },
  body: {
    params: {
      keywords: "", // String, 必填, 查询关键字
      city: "" // String, 不必填, 查询城市pinyin如beijing
    }
  }
}
```
